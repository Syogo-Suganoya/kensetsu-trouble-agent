# 安全確認（中小製造業サプライヤー）

報告に次のいずれかが含まれる／疑われる場合は、**分類やヒアリングより先に**以下だけを短く伝える。

| 兆候 | 最初に伝えること |
|---|---|
| 挟まれ・巻き込まれ・切断・意識がない・大量出血 | 「すぐ機械を非常停止。無理に引き抜かず119番。社内の安全担当・上長へ連絡を。」 |
| 火災・発煙・薬品漏れ・ガス臭 | 「119番、周囲の人を退避。可能なら元電源・元栓を止める。上長へ即連絡を。」 |
| 感電・熱中症の疑い | 「電源を切ってから救助、119番。涼しい場所へ移し、上長へ連絡を。」 |
| 設備・金型が異音・異常振動で「壊れそう」 | 「設備を停止し、周囲に人を近づけない。設備担当・上長へ連絡を。」 |

- 人身事故は `severity: 高`、分類は `安全・労災`。
- 労基署への報告要否は社内の安全担当の判断事項として、対応案で確認を促す（AIは判断しない）。
