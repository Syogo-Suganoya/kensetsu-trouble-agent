# ヒアリング項目（物流・トラック運送）

運転中の入力はさせない。**「停車中ですか？」を最初に確認**し、運転中なら「安全な場所に停めてから続きを」とだけ返す。

## 必須（ログ登録に必要）

| 項目 | JSON | 聞き方の例（選択肢付き） |
|---|---|---|
| 何が起きたか | `summary.what` | 報告文から作る。荷待ちなら到着時刻と呼ばれた（呼ばれる見込みの）時刻 |
| いつ | `summary.when` | 「到着／発生は何時？」＋**指定時刻・予約時刻** |
| どこで | `summary.where` | 「積地・卸地（センター名／荷主名）は？ 事故なら場所（道路名・IC名）」 |
| 影響範囲 | `summary.impact` | 「次の配送に ①間に合わない ②ギリギリ ③影響なし」＋休息期間が取れるか |
| 関係者 | `summary.stakeholders` | 「荷主・着荷主、元請の運送会社、自社の配車担当は？」 |
| 報告者 | `reporter` | 「あなたは ①ドライバー ②運送会社（配車・運行管理・事務） ③荷主・元請」「荷主から見て何次請けですか？（荷主と直接=1、わからなければ飛ばしてOK）」 |
| 現場名 | `site` | 「便名・コース名、または積地→卸地（例：〇〇物流センター→△△店）」 |

`reporter.role` は `ドライバー` / `運送会社` / `荷主・元請`。

## あると後で効く（聞けたら `impact` や `what` に含める）

- **荷待ちの時刻**：到着→受付→積込み（荷卸し）開始→終了→出発 の各時刻（わかる範囲）
- **附帯作業の内容と時間**：誰に頼まれたか、契約（運送依頼書）に書かれているか
- **車両**：車格（4t・10t 等）— 大型車の荷待ち等は乗務記録への記載対象になるため、配車・運行管理側で記録してもらう
- **待機・附帯作業の料金**：契約上の定めがあるか、請求できているか
- **写真**：荷崩れ・破損・事故現場・受付の混雑状況

## 聞き方のルール

- 1回1〜2問、番号で答えられる形にする。**ドライバーには特に短く**。
- 報告文から推測できるものは質問にせず、確認サマリで「合ってますか？」とまとめて確認する。
- 3往復で埋まらなければ `不明` のまま登録し、後から `trouble-log` で追記できると伝える。
