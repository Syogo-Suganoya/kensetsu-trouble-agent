# ③ 今後の対応案（テンプレート）

```
【対応案】{trouble_id} {subcategory}（重要度：{severity}）

▼ いますぐ（〜1時間）
1. {安全確保・作業中止/組替え・一次連絡 など}
2. {写真・記録を残す}

▼ 今日中
1. {判断待ち事項と判断者・判断時刻}
2. {手配・調整}

▼ 明日以降
1. {是正・再手配・工程の組み直し}

▼ 元請に確認・合意しておくこと
・{工程変更の承認／追加費用の扱い／指示の書面化 など}

▼ 記録しておくこと（後で交渉材料になる）
・待機した人数と時間：{【要確認】}
・指示を受けた日時・指示者：{}
・写真：{有/無 → 無なら撮影}
```

## 書き方メモ

- 各項目は「誰が・何を」まで書く（例：「職長：ポンプ車を15時まで待機依頼」）。
- 選択肢がある場合は案A/案Bを示し、それぞれのデメリット（費用・工期）を一言添える。
- 対応案は提案であり、最終判断は元請・現場責任者が行う前提で書く（「〜を推奨」「〜をご検討ください」）。
