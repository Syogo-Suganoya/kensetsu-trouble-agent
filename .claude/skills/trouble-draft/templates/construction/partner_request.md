# ② 協力会社向け相談・依頼文（テンプレート）

## LINE／ショートメッセージ用（3〜6行）

```
{相手の会社名} {氏名}さん
お疲れさまです、{会社名}の{氏名}です。
{現場名}で{what を短く}。
{依頼事項を1つ：例「明日8時から2名、応援お願いできますか？」}
{期限}までに可否だけでも返信いただけると助かります。
```

## メール用

```
件名：【ご相談】{現場名} {依頼事項の要約}（{期限}までにご回答希望）

{相手の会社名}
{氏名}様

いつもお世話になっております。{会社名}の{氏名}です。
{現場名}にて{what}が発生しており、ご相談させてください。

■ ご依頼内容
・内容：{何を}
・日時：{いつ}
・場所：{where}
・数量／人数：{【要確認】を含めてよい}

■ 背景
・{impact を1〜2行}

■ ご回答のお願い
{期限}までに、可否・条件（費用・日程）をご返信いただけますでしょうか。
難しい場合も、その旨だけでもお知らせいただけますと助かります。

{会社名} {氏名} {連絡先【要確認】}
```

## 書き方メモ

- 依頼は1通につき原則1件。複数ある場合は番号を振る。
- 費用が発生しうる依頼（応援・特急手配・再納品）は「条件（費用・日程）」の回答を必ず求める。後から揉めないため。
- 相手に原因がある場合（誤納品など）も非難せず、「〇〇の件、確認させてください」と事実確認から入る。
