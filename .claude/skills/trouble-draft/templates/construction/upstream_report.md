# ① 元請向け状況報告（テンプレート）

```
件名：【{重要度が高なら「至急」}状況報告】{現場名} {subcategory}（{発生日時}）

{宛先の役職} {氏名}様
（宛名不明なら「〇〇作業所 ご担当者様」）

お疲れさまです。{会社名}の{氏名}です。
{what を1文で}のため、ご報告します。

■ 状況
・発生：{when}／場所：{where}
・内容：{what の詳細}

■ 影響
・{impact：作業・工程・人員への影響}

■ 現在の対応
・{すでに実施したこと}
・{次に行うこと と その時刻}

■ ご判断・ご確認をお願いしたい事項
・{判断事項}（{期限}までにご回答いただけますと助かります）

本件に伴う待機・追加作業の時間は記録しておき、必要に応じて別途ご相談させてください。
{次回報告の予定：「〇時に続報します」}

{会社名} {氏名} {連絡先【要確認】}
```

## 書き方メモ

- 冒頭3行で「何が・どうなる・何を判断してほしいか」がわかるようにする。
- 安全・事故の場合は「速報」と明記し、被災者の状態と実施済み措置を最優先で書く。原因の推測は書かない。
- 設計変更・口頭指示の場合は「ご指示内容の確認のため、変更指示書（またはメールでのご指示）をいただけますと幸いです」を必ず入れる。
