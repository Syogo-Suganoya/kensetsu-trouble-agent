# ③ 今後の対応案（テンプレート）

```
【対応案】{trouble_id} {subcategory}（重要度：{severity}）

▼ いますぐ（〜1時間）
1. {安全確保・休息・一次連絡 など}
2. {時刻・写真を記録}

▼ 今日中
1. {判断待ち事項と判断者・判断時刻（着時刻変更・代走 など）}
2. {配車の組み直し}

▼ 明日以降
1. {再配送・車両修理・乗務計画の見直し}

▼ 荷主・元請に確認・合意しておくこと
・{着時刻変更・分納／待機時間料・附帯作業料の扱い／変更指示の書面化}

▼ 記録しておくこと（後で協議の根拠になる）
・着車・受付・作業開始・終了・出発の時刻：{【要確認】}
・附帯作業の内容・時間・依頼者：
・運行管理側で乗務記録への記載が必要か（車格・荷待ち時間による）：
・運賃・料金について申し入れた日時と回答：

▼ 参考
・荷待ち・附帯作業・運賃に関する制度（記録、標準的な運賃、荷主の取組）は国土交通省の最新情報を確認する。
```

## 書き方メモ

- **拘束時間・休息期間を削る案は出さない。** 間に合わない場合は時刻変更・代走・翌日便を案として出す。
- 各項目は「誰が・何を」まで書く（例：「配車：代走可能な協力会社に15時までに打診」）。
- 対応案は提案であり、最終判断は運行管理者・配車責任者が行う前提で書く。
