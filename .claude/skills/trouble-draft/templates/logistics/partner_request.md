# ② 協力運送会社依頼（テンプレート）

## LINE／ショートメッセージ用（3〜6行）

```
{相手の会社名} {氏名}さん
お疲れさまです、{会社名}の{氏名}です。
{日付}の{積地→卸地}、{車格}で1台お願いできますか？
積込み{時刻}／荷姿{荷姿}／運賃・待機料は{条件【要確認】}。
{期限}までに可否だけでも返信いただけると助かります。
```

## メール用

```
件名：【ご依頼】{日付} {積地→卸地} {車格}（{期限}までにご回答希望）

{相手の会社名}
{氏名}様

いつもお世話になっております。{会社名}の{氏名}です。
{what}のため、下記の運行をご相談させてください。

■ ご依頼内容
・日時：積込み {日時}／納品 {日時}
・積地：{住所・センター名}
・卸地：{住所・店舗名}
・車格・台数：
・荷姿・重量：{【要確認】を含めてよい}
・附帯作業：{有無と内容。無ければ「なし」と明記}

■ 条件
・運賃：{【要確認】}
・待機時間料・附帯作業料：{【要確認】}
・高速代：{【要確認】}

■ ご回答のお願い
{期限}までに、可否・条件をご返信いただけますでしょうか。

{会社名} {氏名} {連絡先【要確認】}
```

## 書き方メモ

- **附帯作業の有無と待機時間料・高速代の扱いを必ず明記する**（自社が元請側でも、多重下請で条件が曖昧なまま流さない）。
- 事故・故障時の積替え依頼は、場所（道路名・IC・住所）と積荷の状態を最初に書く。
