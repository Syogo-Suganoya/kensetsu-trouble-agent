# ① 荷主・元請報告（テンプレート）

## ショートメッセージ／電話メモ用（配車担当・元請へ第一報）

```
{相手の会社名} {氏名}様
{会社名}の{氏名}です。{便名/積地→卸地}の件、{what を短く}。
{到着見込み：「〇〇着は14:30頃の見込みです」}
{判断を仰ぐこと：「着時刻の変更を先方にご連絡いただけますか？」}
```

## メール用（詳報）

```
件名：【{重要度が高なら「至急」}ご報告】{便名/積地→卸地} {subcategory}（{発生日時}）

{相手の会社名} {部署} {氏名}様

いつもお世話になっております。{会社名}の{氏名}です。
{what を1文で}につき、ご報告します。

■ 状況（時刻は実績）
・{着車 9:00／受付 9:05／積込み開始 11:20／終了 11:50／出発 12:00 など}
・場所：{where}
・内容：{what の詳細}

■ 配送への影響
・{impact：到着見込み時刻、後続便、休息期間への影響}

■ 現在の対応
・{すでに実施したこと}
・{次に行うこと と その時刻}

■ ご判断・ご確認をお願いしたい事項
・{判断事項：着時刻の変更・分納・翌日便 など}（{期限}までにご回答いただけますと助かります）

本件で発生した待機・附帯作業の時間は記録しておき、料金の扱いについて別途ご相談させてください。

{会社名} {氏名} {連絡先【要確認】}
```

## 書き方メモ

- 報告者が下請運送会社の場合、宛先は**元請運送会社**。荷主への連絡を元請にお願いするか、自社から連絡してよいかを確認する一文を入れる。
- 事故は「速報」と明記し、けが人の有無・積荷の状態・実施済み措置を最優先で書く。原因の推測は書かない。
- 荷待ち・附帯作業は必ず時刻（実績）で書く。
