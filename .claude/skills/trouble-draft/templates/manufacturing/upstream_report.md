# ① 発注元報告（テンプレート）

```
件名：【{重要度が高なら「至急」}ご報告】{品番/案件名} {subcategory}（{発生日時}）

{発注元の会社名} {部署} {氏名}様
（宛名不明なら「〇〇株式会社 購買部 ご担当者様」）

いつもお世話になっております。{会社名}の{氏名}です。
{what を1文で}につき、ご報告します。

■ 状況
・品番／ロット：{【要確認】を含めてよい}
・発生／ご連絡受領：{when}　場所：{where}
・内容：{what の詳細}

■ 納入・数量への影響
・{impact：納期・数量・残業や休日稼働の要否}

■ 現在の対応
・{すでに実施したこと（出荷停止・選別・材料手配 など）}
・{次に行うこと と その時刻}

■ ご判断・ご確認をお願いしたい事項
・{判断事項：納期変更・分納・特採・費用の扱い など}（{期限}までにご回答いただけますと助かります）

本件に伴う追加の工数・費用（{残業・休日稼働・選別・特急手配 など}）は記録しておき、別途ご相談させてください。
{次回報告の予定：「〇日〇時までに続報します」}

{会社名} {部署} {氏名} {連絡先【要確認】}
```

## 書き方メモ

- 冒頭3行で「何が・納入にどう影響するか・何を判断してほしいか」がわかるようにする。
- 増産・前倒しは「対応可否」「条件（数量・納期）」「費用の協議希望」を必ずセットで書く。
- 図面・仕様変更は「改訂図面または書面でのご指示をいただけますと幸いです」を必ず入れる。
- 価格協議の申し入れは、根拠となるコスト変化（時期・率）と「協議の場を設けていただけますでしょうか」で締める。
- 品質クレームは「事実→暫定対策→恒久対策の報告予定日」の順。原因確定前に責任を認める表現はしない。
