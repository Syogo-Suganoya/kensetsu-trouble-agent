# ② 仕入先・外注先依頼（テンプレート）

## LINE／ショートメッセージ用（3〜6行）

```
{相手の会社名} {氏名}さん
お世話になっております、{会社名}の{氏名}です。
{品番/材料名}の件で{what を短く}。
{依頼事項を1つ：例「〇日までに材料〇kg、前倒し納入できますか？」}
{期限}までに可否と条件だけでもご返信いただけると助かります。
```

## メール用

```
件名：【ご相談】{品番/材料名} {依頼事項の要約}（{期限}までにご回答希望）

{相手の会社名}
{氏名}様

いつもお世話になっております。{会社名}の{氏名}です。
{what}のため、ご相談させてください。

■ ご依頼内容
・品名／品番：
・数量：{【要確認】を含めてよい}
・希望納期：
・納入場所：

■ 背景
・{impact を1〜2行}

■ ご回答のお願い
{期限}までに、可否・条件（費用・納期）をご返信いただけますでしょうか。
難しい場合も、その旨だけでもお知らせいただけますと助かります。

{会社名} {氏名} {連絡先【要確認】}
```

## 書き方メモ

- 自社が発注する側でも、自社がされて困る依頼の仕方（費用の話をしない前倒し要求など）はしない。**費用・条件の回答を必ず求める。**
- 材料・外注起因の不良が疑われる場合も、非難せず「〇〇の件、事実確認させてください」から入り、ロット・数量・現品の有無を書く。
