# ③ 今後の対応案（テンプレート）

```
【対応案】{trouble_id} {subcategory}（重要度：{severity}）

▼ いますぐ（〜1時間）
1. {安全確保・出荷停止・設備停止・一次連絡 など}
2. {現品・写真・指示内容を記録}

▼ 今日中
1. {判断待ち事項と判断者・判断時刻}
2. {材料手配・生産計画の組替え・選別}

▼ 明日以降
1. {恒久対策・再手配・計画の組み直し}

▼ 発注元に確認・合意しておくこと
・{納期変更・分納／費用負担（残業・休日稼働・選別・余剰在庫）／指示の書面化／価格協議の場}

▼ 記録しておくこと（後で協議の根拠になる）
・依頼・指示を受けた日時・相手・手段（電話／メール／口頭）：
・内示数→確定数、当初納期→要求納期：
・発生した追加工数（残業・休日稼働・選別・手直し）：{【要確認】}
・価格について申し入れた日時と回答：

▼ 参考
・取引条件・価格協議について迷ったら、公正取引委員会・中小企業庁の相談窓口（最新情報を確認）へ相談できる。
```

## 書き方メモ

- 各項目は「誰が・何を」まで書く（例：「生産管理：土曜稼働の人員を15時までに確定」）。
- 選択肢がある場合は案A/案Bを示し、それぞれのデメリット（費用・納期・人の負担）を一言添える。
- 対応案は提案であり、最終判断は自社の責任者が行う前提で書く（「〜を推奨」「〜をご検討ください」）。
