# トーンガイド（物流・トラック運送）

共通ルール（[../common-tone.md](../common-tone.md)）に加えて以下に従う。
慣用語：積地・卸地、着車、バース、荷待ち、荷役、附帯作業、傭車、配車、延着、車格 など。

## この業種で特に気をつけること

- **荷待ち・附帯作業は「事実の時刻」で書く**（「長時間お待ちしました」ではなく「9:00着、11:20積込み開始」）。時刻の記録そのものが運賃・料金協議の根拠になる。
- **ドライバーの休息・安全を削る約束をしない**。「休憩を削って間に合わせます」は書かない。延着の可能性は早めに、代替案（時刻変更・分納・翌日便）と一緒に伝える。
- 契約外の附帯作業を頼まれた場合、その場で断る文面ではなく「作業内容の確認」と「料金の扱いの確認」を依頼する形にする。
- 運賃・料金の話は、要求ではなく「協議の申し入れ」として、根拠（待機時間の累計、燃料価格の変化、附帯作業の回数）を添えて書く。
  - 背景：荷待ち・荷役の記録、標準的な運賃（待機時間料・積込料等を含む）、荷主の荷待ち削減の取組など、国の制度が整備されてきている。ただし文面で制度名を出して相手を責めることはしない。制度の詳細は国土交通省の最新情報で確認するよう対応案に書く。
- 多層構造では、荷主へ直接連絡してよいかは契約・元請との関係による。**報告者が下請の場合、①はまず元請運送会社宛て**にする。

## 宛先別

| 宛先 | 敬語レベル | 注意点 |
|---|---|---|
| 荷主（物流部門・出荷担当） | 丁寧語＋謙譲語 | 到着見込み時刻・影響・判断を仰ぐ事項を数字で。 |
| 元請運送会社（配車担当） | 丁寧語 | 延着・荷待ちの事実を早く短く。荷主への連絡をお願いするか、自社から連絡してよいかを確認。 |
| 着荷主・倉庫 | 丁寧語 | 到着見込み時刻と受入可否だけ。 |
| 協力運送会社（傭車先） | 丁寧語 | 依頼内容（車格・積地卸地・日時・荷姿）と運賃・待機料の条件、回答期限を明確に。 |
| ドライバー（LINE） | 丁寧だがくだけてよい | 2〜4行。次にどこへ行くか・何時か・休憩の指示だけ。 |

## NG → OK 例

- NG「長時間お待ちしましたが、なんとか間に合わせます」
  OK「9:00に着車し、11:20に積込みを開始しました（荷待ち2時間20分）。〇〇店への到着は14:30頃の見込みです。」
- NG「ついでに棚入れもやっておきました」
  OK「荷卸し後の棚入れ作業（約40分）のご依頼をいただきました。作業内容と料金の扱いについて確認させてください。」
- NG「休憩なしで走らせます」
  OK「休息期間を確保したうえで、翌朝8時の納品に変更させていただけますでしょうか。」
