# 分類別の重点（物流・トラック運送）

ドラフト種別：① `荷主・元請報告` ② `協力運送会社依頼` ③ `対応案`

| category | ①荷主・元請報告で必ず入れる | ②協力運送会社依頼で必ず入れる | ③対応案の要点 |
|---|---|---|---|
| 荷待ち・荷役時間超過 | 着車・受付・作業開始・終了の時刻、次の配送への影響、**待機時間の記録と料金の扱いの確認** | 後続便の時刻変更・代走の可否 | 乗務記録への記載（運行管理）、荷待ち時刻の継続記録 |
| 配送遅延 | 遅延理由（事実）、到着見込み時刻、代替案（時刻変更・分納・翌日便） | 引継ぎ・代走の可否と条件 | 着荷主への連絡経路、休息期間の確保を優先 |
| 交通事故・車両故障 | 速報：発生時刻・場所・けが人の有無・積荷の状態・配送への影響 | 積替え・代車の手配（車格・場所・時刻） | 運行管理者による事故報告要否の確認、保険会社連絡 |
| 貨物事故（破損・誤配・紛失） | 事実（品名・数量・状態・発見時点）、現品と写真の保全、原因確定前に責任を認めない | （該当する場合）回収・再配送の依頼 | 着荷主への一次連絡、保険・補償の確認は運行管理者から |
| 急な配車変更・キャンセル | 変更内容・指示者・指示時刻、**空車回送・待機の発生と費用の扱いの確認** | 変更後の依頼内容・運賃条件の再確認 | 変更の書面化（メール・依頼書）を依頼 |
| 契約外の附帯作業 | 依頼された作業内容・時間・依頼者、**作業範囲と料金の扱いの確認** | （傭車先が頼まれた場合）作業時間の記録の依頼 | 運送依頼書の記載確認、附帯作業の記録 |
| ドライバー不足・欠勤 | 当日便への影響と対応計画（代走・時刻変更） | 代走依頼（車格・積地卸地・日時・荷姿・運賃・回答期限） | 拘束時間・休息期間を超えない配車 |
| 運賃・料金 | 協議の申し入れ（待機時間の累計・附帯作業の回数・燃料価格の変化）、協議の場の設定依頼 | （該当する場合）傭車運賃の見直しの事前連絡 | 申し入れ日時・相手・回答を記録、相談窓口の確認 |
| 天候・通行止め | 走行中止・迂回の判断根拠（道路情報）、到着見込み・運休の提案 | 運休・日程振替の連絡 | 安全優先、再開判断の時刻 |

## 読み替え

- 報告者が下請運送会社・そのドライバーの場合、①は**元請運送会社宛て**にし、荷主への連絡は元請に依頼するか確認する。
- 報告者が荷主・元請の場合、①は「社内（物流部門・営業）／着荷主向け報告」、②は「運送会社向け依頼」にする。
- 協力運送会社が関係しない場合、②は「ドライバー向け指示（LINE）」にする。
