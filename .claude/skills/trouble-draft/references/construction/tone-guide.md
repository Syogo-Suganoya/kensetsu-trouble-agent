# トーンガイド（建設業）

共通ルール（[../common-tone.md](../common-tone.md)）に加えて以下に従う。
慣用語：打設、段取り、手配、是正、職長、KY、手待ち など。

## 宛先別

| 宛先 | 敬語レベル | 注意点 |
|---|---|---|
| 元請（工事主任・所長） | 丁寧語＋謙譲語 | 判断を仰ぐ事項を明示（「〜のご判断をお願いします」）。長文は嫌われるので要点3行＋詳細。 |
| 協力会社・メーカー | 丁寧語 | 立場が上でも高圧的にしない。依頼事項・期限・回答方法を明確に。 |
| 職長・職人（LINE） | 丁寧だがくだけてよい | 3〜5行。絵文字なし。今日やることだけ。 |
| 発注者・設計監理（報告者が元請の場合） | 丁寧語＋謙譲語 | 速報と今後の報告予定時刻をセットで書く。 |

## NG → OK 例

- NG「大変申し訳ございません。弊社の確認不足により…」（原因未確定）
  OK「13時着予定の生コンが未着のため、状況をご報告します。」
- NG「なんとか今日中にやります」（無償の帳尻合わせを約束）
  OK「本日中の打設可否は14時に判断し、改めてご連絡します。」
- NG「至急お願いします！」
  OK「本日16時までに可否のご回答をお願いできますでしょうか。」
- 口頭での変更指示には必ず「変更指示書（またはメールでのご指示）をいただけますと幸いです」を入れる。
