# 分類別の重点（中小製造業サプライヤー）

ドラフト種別：① `発注元報告` ② `仕入先・外注先依頼` ③ `対応案`

| category | ①発注元報告で必ず入れる | ②仕入先・外注先依頼で必ず入れる | ③対応案の要点 |
|---|---|---|---|
| 急な増産・納期前倒し | 対応可否と条件（数量・納期）、**必要な残業・休日稼働と費用の協議希望** | 材料の追加手配・外注の前倒し可否と費用 | 分納案、無理な場合の代替案、費用記録 |
| 内示変更・発注キャンセル | 内示と確定の差、手配済み材料・仕掛品の数量と金額、**引取り・費用負担の協議希望** | 材料発注の変更・キャンセル可否 | 余剰在庫の扱いを書面で確定 |
| 材料・部品の調達遅延 | 遅延の事実・入荷見込み、納入への影響、分納・代替材の提案 | 納期回答・代替品・分納の可否と回答期限 | 支給品なら発注元に手配状況の確認 |
| 品質不良・クレーム | 事実（品番・ロット・数量・発見場所）、暫定対策（選別・出荷停止）、恒久対策の報告予定日 | 材料・外注起因の疑いがあれば事実確認と調査依頼 | 選別・手直し工数の記録、原因確定前に責任を認めない |
| 設備故障・金型トラブル | 停止時刻・復旧見込み、在庫で持つ日数、貸与型なら所有者として修理の相談 | 修理・部品手配の可否と日時 | 代替設備・外注の検討、復旧判断の時刻 |
| 図面・仕様変更 | 変更箇所・指示者・指示日時、**改訂図面・書面での指示依頼、費用・納期影響の協議希望** | 変更内容の展開、旧仕様品の扱い | 旧図面品の在庫・仕掛の扱いを確定 |
| 人員不足・急な残業 | （発注元に関係する場合のみ）納入への影響と対応計画 | 派遣・協力工場への応援依頼（人数・日時・単価） | 安全・品質リスク、残業・休日出勤の偏りの記録 |
| 価格・支払条件 | 協議の申し入れ（根拠となるコスト変化・時期）、協議の場の設定依頼 | （該当する場合）自社の仕入価格変更の事前連絡 | 申し入れ日時・相手・回答を記録、相談窓口の確認 |
| 安全・労災 | （発注元構内・発注元設備の場合）発生状況・被災者の状態・措置の速報 | 同種作業の一時停止・注意喚起 | 労基署報告要否は社内安全担当が判断 |

## 読み替え

- 報告者が発注元自身の場合、①は「社内（経営層・自社顧客）向け報告」、②は「サプライヤー向け依頼」にする。
- 仕入先・外注先が関係しない場合、②は「社内（班長・作業者）向け共有文」にする。
