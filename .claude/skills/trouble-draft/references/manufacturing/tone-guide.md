# トーンガイド（中小製造業サプライヤー）

共通ルール（[../common-tone.md](../common-tone.md)）に加えて以下に従う。
慣用語：内示、確定、納入、品番、ロット、段取り替え、特採、選別、流出、8D、ECN など。

## この業種で特に気をつけること

- **「断れず無償で帳尻合わせ」を文面で固定しない**。増産・前倒しには「対応可否」と「対応に伴う費用（残業・休日出勤・特急手配）」を必ずセットで書く。
- **価格・支払条件の話は、要求ではなく「協議の申し入れ」として書く**。根拠（原材料・エネルギー・労務費の変化）と、協議の場を設けてほしい旨を丁寧に。
  - 背景：2026年1月施行の改正下請法（中小受託取引適正化法）では、協議に応じない一方的な代金決定などが問題とされる。ただし文面で法令名を出して相手を責めることはしない。記録を残すこと・協議を申し入れた事実を残すことに徹する。制度の詳細は公正取引委員会・中小企業庁の最新情報で確認するよう対応案に書く。
- 品質クレームは、原因が確定するまで「流出させてしまい申し訳ございません」とは書かない。「ご迷惑をおかけしております。現在、事実確認と暫定対策を進めております」に留める。
- 貸与型・支給品の不具合は、所有者が発注元である事実を淡々と書く（修理・保管費用の協議につなげる）。

## 宛先別

| 宛先 | 敬語レベル | 注意点 |
|---|---|---|
| 発注元（購買・生産管理） | 丁寧語＋謙譲語 | 納期・数量・費用を数字で。判断を仰ぐ事項と回答期限を明示。 |
| 発注元（品質保証） | 丁寧語＋謙譲語 | 事実（ロット・数量・発見場所）→暫定対策→恒久対策の予定日の順。 |
| 仕入先・外注先 | 丁寧語 | 自社が発注元側でも高圧的にしない。依頼事項・納期・回答方法を明確に。**自社がされて困ることを下にしない。** |
| 社内（作業者・班長、LINE） | 丁寧だがくだけてよい | 3〜5行。今日の段取りと残業の有無だけ。 |

## NG → OK 例

- NG「承知しました。土曜に出て何とか間に合わせます」
  OK「ご要望の〇日納入は、土曜稼働（4名×8時間）で対応可能です。休日稼働分の費用についてご相談させてください。」
- NG「単価はそのままで結構です」
  OK「原材料価格が前回お見積り時から約〇%上昇しており、価格について協議の場を設けていただけますでしょうか。」
- NG「至急選別します」
  OK「本日中に在庫〇個の全数選別を行います。選別に要した工数は記録し、改めてご報告します。」
