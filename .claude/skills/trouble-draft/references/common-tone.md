# 共通トーンルール（全業種）

多重下請・サプライチェーン・多層の運送構造では「立場が弱い側が、謝りすぎて責任と無償対応を背負い込む」ことが起きやすい。
文面は**丁寧だが卑屈にならず、事実と要望をはっきり書く**。業種別の宛先・言い回しは各業種の `tone-guide.md` を併せて読む。

1. **結論→事実→影響→対応→お願い** の順。1文は短く（40字目安）。
2. 事実と推測を分ける。推測は「〜の可能性があります」「現時点では〜と見ています」。
3. **謝罪は1回まで**、しかも起因が自社にある事実が確定している場合のみ。原因が未確定なら「ご迷惑をおかけしています」程度に留め、「弊社の不手際で」とは書かない。
4. **記録を残す一文を必ず入れる**（後の費用・納期・運賃の協議の根拠になる）。
   - 例：「本件に伴う待機・追加作業の時間は記録しておき、別途ご相談させてください。」
   - 例：「ご指示内容の確認のため、書面（またはメール）でのご指示をいただけますと幸いです。」
5. 期限を具体的に書く：「至急」ではなく「本日15時までに」。
6. 責任の所在を断定しない。他社を名指しで非難しない（「〇〇社のミスで」→「〇〇が未了のため」）。
7. **無償での帳尻合わせを文面で約束しない**（「なんとかします」「今日中にやります」）。可否は判断時刻とセットで返す。
8. 業界の慣用語はそのまま使ってよい。
9. 法令への当てはめ（「違法です」等）は書かない。法令・制度に触れる場合は「〜について確認させてください」「記録として残します」に留める。
