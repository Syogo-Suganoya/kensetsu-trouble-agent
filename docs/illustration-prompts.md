# 挿絵の画像生成プロンプト

README の挿絵（ユースケース・トラブル項目・使い方の流れ）を画像生成AIで作るためのプロンプト集。
Gemini、ChatGPT などの日本語に対応した画像生成AIで、そのまま使える。

## 生成のしかた

1. 各画像のコードブロックを**そのまま丸ごと**コピーして生成する（文字・絵柄・比率・入れないものまで1ブロックに入っている）。
2. 最初に `hero.png` を作り、気に入った1枚を「参照画像」として以降の生成に添付し「この絵柄で」と頼むと、人物と色味がそろいやすい。
3. 画像内の文字は「文字：」に書いたものだけ。生成AIは日本語の文字を崩すことがあるので、誤字・崩れがあれば生成し直すか、ツールの編集機能で直す。文字を変えたいときは「文字：」の「」の中だけ書き換える。
4. `docs/images/<ファイル名>`（拡張子は実際の生成結果に合わせる。現在は .jpeg） に保存する（README から参照済み）。横幅 1600px 程度に縮小してから置くとリポジトリが重くならない。
5. 生成後に末尾の **チェックリスト** を確認する。
